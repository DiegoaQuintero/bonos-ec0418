# Bonos y asistencia — Economía EC0418 (2026-II)

Página pública de consulta para los estudiantes del curso.
Publicada con GitHub Pages desde la raíz de la rama `main`.

`index.html` es un archivo autocontenido: incluye estilos, código y datos, y no
depende de ningún servicio externo. **No se edita a mano**: lo genera
`scripts/generar_web.py` en la carpeta de trabajo del curso.

## Actualizar

1. En la carpeta del curso: `python scripts/generar_web.py`
2. Copiar el `index.html` resultante a este repositorio.
3. `git add . && git commit -m "Actualiza bonos" && git push`

La página queda publicada un par de minutos después.

## Qué NO va aquí

Este repositorio contiene únicamente la página publicada. Los documentos de
identidad, correos institucionales y archivos de trabajo del curso se quedan en el
computador del profesor y nunca se suben.
